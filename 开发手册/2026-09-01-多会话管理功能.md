# 多会话管理 + 解耦架构重构 开发手册（2026-09-01）

> 开发内容：为科研助手添加多会话管理功能（会话列表/新建/切换/自动标题），并将单体 `server.py` 重构为 api / services / repositories 三层解耦架构（工厂式依赖注入）。
>
> 开发时间：2026-09-01

---

## 一、开发目标

1. **多会话管理**：侧栏显示会话列表，支持新建会话、切换会话、自动生成标题、按更新时间排序。
2. **解耦架构**：把业务代码、数据库 CRUD、API 路由彻底分开，采用"最工整、可扩展性最强"的工厂式设计。
3. **Checkpointer 协议扩展**：为 `Checkpointer` 协议新增 `list_threads()`，同步实现 SQLite / Memory / PostgreSQL / MySQL 四种后端。

## 二、架构设计

### 2.1 分层结构

```
app/
├── server.py                  # 薄入口：装配 checkpointer + 调 create_api_router
├── agent_factory.py           # Agent 装配工厂（HITL channel + middleware）
├── config.py                  # 配置加载 + provider 构建
├── api/                       # 路由层（只做 HTTP 适配，无业务逻辑）
│   ├── __init__.py            # create_api_router(checkpointer, config) 工厂
│   ├── chat.py                # /chat/*（SSE 流式、HITL、中止、历史）
│   ├── conversations.py       # /conversations（列表、创建）
│   ├── config.py              # /config（provider 配置）
│   └── workspace.py           # /papers、/baseline/tree
├── services/                  # 业务层（编排逻辑，不感知 HTTP）
│   ├── __init__.py
│   ├── chat_service.py        # 消息发送、HITL 响应、中止、历史
│   ├── conversation_service.py# 会话列表、创建、标题生成
│   └── workspace_service.py   # 论文列表、baseline 树
├── repositories/              # 数据层（数据库 CRUD）
│   ├── __init__.py
│   └── conversation_repo.py   # 会话 CRUD（封装 Checkpointer）
└── static/index.html          # 前端单页（多会话 UI）
```

### 2.2 依赖注入方向

```
server.py
  └─ create_api_router(checkpointer, config)      ← 工厂：装配依赖
       ├─ ConversationRepository(checkpointer)    ← 数据层
       ├─ ConversationService(repo)               ← 业务层
       ├─ WorkspaceService(config)
       ├─ ChatService(config, checkpointer, conversation_service)
       └─ 4 个子 router（chat/conversations/config/workspace）
```

**关键设计**：依赖从外向内注入（`create_api_router` 是唯一装配点），各层之间只依赖接口（`Checkpointer` 协议），不互相 import 具体实现。新增路由只需在 `create_api_router` 里加一行。

## 三、开发过程

### 3.1 Checkpointer 协议扩展（todo 1）

`cubepi/checkpointer/base.py` 新增 `ThreadSummary` dataclass 与 `list_threads()` 协议方法：

```python
@dataclass(frozen=True)
class ThreadSummary:
    thread_id: str
    title: str
    message_count: int
    updated_at: float

class Checkpointer(Protocol):
    ...
    async def list_threads(self) -> list[ThreadSummary]: ...
```

四个后端实现：

- **SQLite**（`sqlite.py`）：`SELECT DISTINCT thread_id FROM messages UNION SELECT thread_id FROM thread_extra` → 每个 thread 查 `extra_json` 取 title、`COUNT(*)` / `MAX(created_at)` → 按 updated_at 倒序。
  - **坑**：`MAX(created_at)` 对无消息 thread 返回 `None`，直接 `or 0.0` 处理（否则 TestClient 报 `TypeError: '<' not supported between instances of 'float' and 'NoneType'`）。
- **Memory**（`memory.py`）：遍历 `self._store`，title 取 `data.extra.get("title", "")`，updated_at=0.0。
- **PostgreSQL**（`postgres/checkpointer.py`）：`cubepi_threads` 表 + `EXTRACT(EPOCH FROM t.updated_at)` + 子查询 COUNT。
- **MySQL**（`mysql/checkpointer.py`）：`JSON_UNQUOTE(JSON_EXTRACT(t.extra, '$.title'))` + `UNIX_TIMESTAMP(t.updated_at)`。

### 3.3 services 层（todo 3）

`app/services/conversation_service.py`：

```python
_CONV_PREFIX = "conv_"          # 会话 ID 前缀
_TITLE_MAX_LEN = 20             # 标题截取长度
_DEFAULT_TITLE = "新会话"

def _generate_conversation_id() -> str:
    return f"conv_{uuid.uuid4().hex[:6]}"   # conv_8f3a2b 短格式

def _title_from_text(text: str) -> str:
    cleaned = re.sub(r"\s+", " ", text).strip()
    return cleaned[:_TITLE_MAX_LEN] if cleaned else _DEFAULT_TITLE

class ConversationService:
    async def list_conversations(self) -> list[dict]: ...  # _strip_prefix 去 user_id: 前缀
    async def create_conversation(self) -> dict: ...       # 懒创建：仅生成 ID
    async def ensure_title(self, thread_id, first_message) -> None:
        # 已有标题不覆盖；否则用首条消息前 20 字
```

`app/services/chat_service.py`（从 server.py 迁移）：

```python
class ChatService:
    def __init__(self, config, checkpointer, conversation_service): ...

    async def post_message(self, user_id, conversation_id, text):
        thread_id = f"{user_id}:{conversation_id}"
        run_id = uuid.uuid4().hex
        # 首条消息自动生成会话标题（先于 agent 构建！）
        await self._conversation_service.ensure_title(thread_id, text)
        agent = self._build_agent(thread_id, run_id)
        queue = asyncio.Queue()
        agent.subscribe(lambda event, signal=None: queue.put_nowait(event))
        task = asyncio.create_task(agent.prompt(text, run_id=run_id))
        return queue, task
```

**关键 bug 修复**：`ensure_title` 必须放在 `_build_agent()` **之前**。原实现先构建 agent（内部 `build_model()` 在未配置 LLM 时抛 `RuntimeError`），导致标题永远不会生成、新会话不落库。

### 3.4 api 路由层（todo 4）

`app/api/__init__.py` 工厂：

```python
def create_api_router(checkpointer: Checkpointer, config: AppConfig) -> APIRouter:
    repo = ConversationRepository(checkpointer)
    conversation_service = ConversationService(repo)
    workspace_service = WorkspaceService(config)
    chat_service = ChatService(config, checkpointer, conversation_service)
    router = APIRouter()
    router.include_router(create_chat_router(chat_service))
    router.include_router(create_conversations_router(conversation_service))
    router.include_router(create_config_router())
    router.include_router(create_workspace_router(workspace_service))
    return router
```

各子路由：

- `chat.py`：`POST /chat/{id}/messages`（SSE）、`POST /chat/{id}/respond`（catch `HitlNoPendingRequest`→404、`HitlStaleAnswer`→409）、`POST /chat/{id}/abort`、`GET /chat/{id}/pending`、`GET /chat/{id}/history`。
- `conversations.py`：`GET /conversations`（列表）、`POST /conversations`（创建）。
- `config.py`：`GET/POST /config`（全局运行时配置）。
- `workspace.py`：`GET /papers`、`GET /baseline/tree`。

## 四、设计决策记录

| 决策 | 理由 |
|------|------|
| 会话 ID 用 UUID 短格式（`conv_8f3a2b`） | 避免暴露自增序号，防枚举 |
| 会话懒创建（POST 只生成 ID，首条消息才落库） | 避免空会话污染列表 |
| 标题自动取首条用户消息前 20 字 | 零成本、可读性好 |
| 更新时间取 messages 表 `MAX(created_at)` | 无需额外维护字段 |
| 删除会话 MVP 不做 | 保持范围最小，后续可加 |
| 多用户保持 demo-user | 认证占位，`_current_user_id()` 单点替换 |
| 配置内存存储不持久化 | MVP 简化；重启后需重新配置 |
