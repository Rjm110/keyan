# 修复：流式输出每个 token 独立气泡（2026-08-31）

> 开发内容：修复前端 SSE 流式输出时每个 token 变成独立气泡的问题。
>
> 开发时间：2026-08-31

---

## 一、问题现象

用户发送"你好"后，DeepSeek 的回复被拆成几十个独立气泡逐个显示：

```
你好
！
我是
科研
助手
，
可以
帮你
把
论文
中的
方法
落地
到
baseline
代码
中
。
...
```

而不是在一个气泡内流式输出。

## 二、根因分析

`app/static/index.html` 的 `sendMessage` 中，SSE 帧处理调用：

```js
handleSSEFrame(frame, { typing, setAssistant: d => { assistantDiv = d; } });
```

`ctx` 对象字面量里**没有 `assistantDiv` 属性**——`setAssistant` 设置的是 `sendMessage` 作用域的局部变量 `assistantDiv`，而 `handleSSEFrame` 里读的是 `ctx.assistantDiv`，永远是 `undefined`。

因此每个 `delta` 事件都走 `if (!div)` 分支创建新气泡：

```js
if (event === "delta") {
  let div = ctx.assistantDiv;   // 永远是 undefined！
  if (!div) {
    div = addMsg("assistant", "");  // 每次都新建气泡
    ctx.setAssistant(div);
  }
  div.textContent += data;
}
```

## 三、解决方案

让 `ctx` 对象持有 `assistantDiv` 状态，`setAssistant` 更新 `ctx.assistantDiv`：

```js
const ctx = {
  typing,
  assistantDiv: null,
  setAssistant: d => { ctx.assistantDiv = d; },
};

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  const frames = buffer.split(/\r?\n\r?\n/);
  buffer = frames.pop();
  for (const frame of frames) {
    handleSSEFrame(frame, ctx);
  }
}
```

同时删除了 `sendMessage` 中不再需要的 `let assistantDiv = null;` 局部变量。

## 四、验证方式

1. **浏览器验证**：发送"你好"，DeepSeek 回复在**一个气泡**内流式输出（`#messages` 只有 2 条：1 user + 1 assistant）。
2. **静态检查**：`uv run mypy app/`（0 错误）、`uv run ruff check app/`（全过）、`uv run pytest app/tests/ -q`（14 passed）。

## 五、问题与解决

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 流式输出每个 token 独立气泡 | `ctx` 对象没有 `assistantDiv` 属性，`setAssistant` 设置的是外部局部变量，`handleSSEFrame` 读 `ctx.assistantDiv` 永远为 undefined | `ctx` 持有 `assistantDiv` 状态，`setAssistant` 更新 `ctx.assistantDiv` |
