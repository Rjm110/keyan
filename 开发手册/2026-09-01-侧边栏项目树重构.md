# 侧边栏项目树重构 开发手册（2026-09-01）

> 开发内容：将科研助手侧边栏从"项目列表 + 会话列表"两个平铺区块，重构为**项目树**（项目下嵌套会话），每个项目显示真实路径、提供添加会话/重命名/删除操作。
>
> 开发时间：2026-09-01

---

## 一、开发目标

1. **项目树侧边栏**：侧边栏以树形结构展示项目，每个项目下嵌套其会话列表。
2. **可见项目路径**：每个项目名称下方显示真实目录路径，点击可复制。
3. **每项目操作**：每个项目头提供 ＋（添加会话）/ ✎（重命名）/ ✕（删除项目）三个操作按钮（hover 显示）。
4. **展开状态管理**：默认只展开当前项目；点击项目头切换项目并展开；点击当前项目头仅折叠/展开。

## 二、改动清单

### 2.1 后端：新增全量会话列表 API

`app/api/__init__.py` 新增 `GET /conversations`：

```python
@router.get("/conversations")
async def list_all_conversations() -> dict:
    """列出全部会话（按更新时间倒序，含 project_id 字段）。"""
    conversations = await conversation_service.list_conversations()
    return {"conversations": conversations}
```

- 复用 `ConversationService.list_conversations()`（`project_id=None` 时列出全部）。
- 返回每条会话的 `id / project_id / title / message_count / updated_at`，供前端按 `project_id` 分组。
- 旧格式 thread_id（无项目段）由 `_project_id_from_thread()` 归入 `default` 项目。

### 2.4 前端 JS：渲染与交互

新增/重写函数：

| 函数 | 作用 |
|---|---|
| `loadProjects()` | 拉取 `/projects` + `/conversations`，按 `project_id` 分组渲染项目树 |
| `toggleProject(id)` | 展开/折叠项目；展开非当前项目时自动切换 |
| `switchProject(id)` | 切换当前项目：重置 `conversationId`、展开当前折叠其他、清空消息区、刷新 baseline |
| `copyPath(path)` | 复制项目路径到剪贴板 + toast 提示 |
| `newProject()` | 目录浏览模态框 → POST /projects → 切换 |
| `renameProject(id, name)` | 输入模态框 → PATCH → 刷新树 |
| `deleteProject(id, name)` | 确认 → DELETE → 若删当前项目则切到第一个剩余项目 |
| `deleteConversation(projId, id)` | 确认 → DELETE → 若删当前会话则切到第一个剩余会话或新建 |
| `switchConversation(projId, id)` | 跨项目切换会话（先切项目再加载历史） |
| `newConversation(projId)` | POST 创建会话（懒创建），非当前项目下先切换 |
| `showToast(msg)` | 轻量底部 toast 提示（2s 自动隐藏） |

关键状态：

```js
let expandedProjects = {};  // {projectId: true/false} 展开状态
```

默认展开逻辑：`expandedProjects[p.id] !== undefined ? expandedProjects[p.id] : (p.id === projectId)` —— 首次加载只展开当前项目。

## 三、设计决策

1. **会话懒创建**：`POST /conversations` 只生成 ID 不落库（沿用既有设计），因此新建会话后树中不显示，直到首条消息发送。前端 `newConversation` 直接设置 `conversationId` 并清空消息区，用户发消息后会话自然出现在树中。
2. **全量会话一次拉取**：`loadProjects` 同时请求 `/projects` 与 `/conversations`，前端按 `project_id` 分组，避免 N+1 请求。
3. **hover 显示操作按钮**：`.proj-actions` 默认 `display:none`，hover 项目头时显示，保持界面简洁。
4. **路径点击复制**：`.proj-path` 点击调用 `navigator.clipboard.writeText`，失败时 toast 提示手动复制（非 HTTPS 环境剪贴板 API 受限）。
