# 修复：工具调用状态显示在内容输出前面（2026-08-31）

> 开发内容：修复工具调用状态（`✔ list_files 完成`）显示在 assistant 内容气泡之后的问题，改为显示在内容前面。
>
> 开发时间：2026-08-31

---

## 一、问题现象

用户发送"查看 baseline 目录"后，工具调用状态出现在内容输出**中间/后面**：

```
（内容…）
✔ list_files 完成
✔ list_files 完成
✔ read_file 完成
（内容…）
```

用户希望工具调用状态显示在内容输出的**前面**：

```
✔ list_files 完成
✔ list_files 完成
✔ read_file 完成
（内容…）
```

## 二、根因分析

`app/static/index.html` 的 `handleSSEFrame` 中：

- `tool_start` / `tool_end` 事件创建/更新的工具气泡是 `addMsg("tool", ...)` **append 到消息列表末尾**的。
- `delta` 事件创建/更新的 assistant 内容气泡也是 append 到末尾的。
- 由于 SSE 事件顺序是：`tool_start` → `delta`（内容开始）→ `tool_end` → `delta`（内容继续），工具气泡可能被内容气泡"夹住"或出现在内容后面。

## 三、解决方案

在 `tool_start` 和 `tool_end` 时，把工具气泡**插入到 assistant 内容气泡之前**：

```js
} else if (event === "tool_start") {
  const info = JSON.parse(data);
  toolDiv = addMsg("tool", `▶ ${info.name} 执行中…`);
  // 若 assistant 气泡已存在，把工具状态插到它前面
  if (ctx.assistantDiv) {
    $("#messages").insertBefore(toolDiv, ctx.assistantDiv);
  }
} else if (event === "tool_end") {
  if (toolDiv) {
    toolDiv.textContent = `✔ ${JSON.parse(data).name} 完成`;
    toolDiv.classList.add("done");
    // 确保工具状态显示在 assistant 内容气泡前面
    if (ctx.assistantDiv && toolDiv.nextSibling !== ctx.assistantDiv) {
      $("#messages").insertBefore(toolDiv, ctx.assistantDiv);
    }
  }
}
```

## 五、问题与解决

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 工具调用状态显示在内容后面 | 工具气泡 append 到末尾，被内容气泡夹住 | `insertBefore` 把工具气泡插到 assistant 内容气泡之前 |
